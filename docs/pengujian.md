# Rencana Pengujian

Rencana berdasarkan proposal:
1. Black box untuk setiap fitur FR-01 sampai FR-23.
2. Uji hak akses: karyawan tidak dapat membuka halaman owner; paket gratis tidak dapat membuka fitur premium.
3. Uji keamanan dasar: SQL injection, XSS, CSRF, sesi login, dan pembatasan percobaan login.
4. Uji modul AI dengan data contoh yang mensimulasikan penurunan omzet.
5. Uji pemisahan data multi-tenant antar-owner.
6. Uji transaksi order agar header dan rincian tidak tersimpan sebagian.

Catat skenario, data uji, hasil yang diharapkan, hasil aktual, dan status lulus/gagal.
