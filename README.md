# Sistem Manajemen Laundry Berbasis AI

Aplikasi manajemen laundry berbasis web menggunakan PHP Native dan MySQL.

## Teknologi
- PHP Native
- MySQL
- HTML, CSS, JavaScript
- AI untuk analisis dan insight laundry

## Struktur
- admin: pengelolaan sistem
- owner: fitur pemilik laundry
- karyawan: fitur karyawan
- auth: autentikasi
- config: konfigurasi database
- database: struktur database
- ai: modul AI
- public: aset CSS, JavaScript, dan gambar

## Instalasi
1. Clone repository.
2. Buat database MySQL.
3. Import `database/schema.sql`.
4. Sesuaikan koneksi di `config/database.php`.
5. Jalankan melalui XAMPP.
